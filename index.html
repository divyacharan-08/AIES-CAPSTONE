CSP Variable-Ordering Solver

Comparing Minimum Remaining Values (MRV) vs Fixed Variable Ordering (FVO) under identical constraints.

Algorithm A Fail-First Heuristic

Minimum Remaining Values (MRV)

Selects the unassigned course with the fewest legal examination slots remaining. Prunes search trees early by encountering unavoidable dead-ends at higher decision levels.

  • 1 Calculate available valid slots for all unassigned courses.
  • 2 Select course with minimum legal domain size.
  • 3 Tie-breaker: Degree Heuristic (most conflicting neighbors), then lexicographical.
  • 4 Assign first valid slot according to shared value ordering.
  • 5 Backtrack immediately when domain wipeout is detected.
Algorithm B Static Ordering

Fixed Variable Ordering (FVO)

Courses are considered in a predefined static order (order of declaration). Without domain awareness, deep futile subtrees are repeatedly explored before backtracking.

  • 1 Arrange courses in a predetermined fixed sequence.
  • 2 Select the next course in static sequence.
  • 3 Check consistency against already assigned conflicting neighbors.
  • 4 Assign first valid slot according to identical value ordering.
  • 5 Backtrack if no valid slot can be assigned.

CSP Analysis: Why MRV Reduces Backtracking

The Minimum Remaining Values (MRV) heuristic—also known as the Most Constrained Variable or Fail-First heuristic—selects the variable with the fewest remaining legal values in its domain.

In contrast, Fixed Variable Ordering (FVO) assigns variables blindly according to a static list. If an unassigned course down the line has already had all its valid time slots wiped out by earlier assignments, Fixed Ordering continues to fruitlessly explore combinatorial branches before finally reaching that doomed course and realizing it cannot be scheduled.

By prioritizing the course with the smallest domain, MRV detects unfeasible assignments immediately near the root of the search tree, pruning entire exponential subtrees of backtracks.
